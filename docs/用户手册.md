# EarRove（聆途）用户手册

**EarRove（聆途）**（Version 1.0）

## 用户手册

## 一、前言

感谢您使用 **EarRove（聆途）**。本软件是面向视障及低视力用户的 **Android 辅助应用**，帮助您在出行时获得 **步行导航与路口提示**，在日常生活中通过 **拍照或相册** 识别图片中的文字并以 **语音朗读**，同时配合 **震动反馈** 与 **读屏（TalkBack）** 优化，提升独立出行与信息获取的便利性。

为便于您与家人、陪护人员快速掌握主要操作，特编写本手册。手册包括：**软件功能概览**、**各功能模块的使用步骤**、**注意事项与常见问题**。因软件会持续升级，若界面或流程与本文不完全一致，请以安装到手机上的实际版本为准，并可结合同目录下《使用说明-详细版.md》（偏技术向）查阅细节。

若您有功能建议或问题反馈，欢迎通过应用内或项目提供的渠道联系开发方。

---

## 二、系统功能

EarRove 主要包含以下功能模块：**启动与合规（隐私、权限）**、**首页**、**导航**、**文字识别（OCR）**、**设置**、**帮助**。各模块相互配合，建议在首次使用时按顺序完成隐私同意与权限授权，再使用导航与 OCR。

### 运行环境与安装概要

- **设备：** Android 手机或平板，系统版本需满足应用要求的最低版本（见应用商店或安装包说明）。
- **网络：** 导航、语音识别、文字识别等能力在多数场景下需要 **网络连接**；请保持移动数据或 WLAN 可用。
- **硬件：** 推荐使用具备 **定位（GPS）**、**摄像头**、**麦克风**、**震动** 的真机，以获得完整体验。
- **安装：** 通过开发者提供的 APK 安装包或内部分发渠道安装；首次打开前无需单独输入用户名密码（本应用当前不以传统「账号登录」作为使用门槛）。

> 此处可插入：应用图标或安装完成后的启动画面截图

### 首次启动与隐私、权限

首次启动时，应用会引导您完成：

1. **应用隐私政策** 与 **百度地图相关隐私** 的同意（需分别确认后才会进入主界面）。
2. **运行所需权限**：如 **定位**、**相机**、**麦克风** 等；若暂时拒绝，部分功能可能不可用或体验降级，应用会给出说明。
3. 若开发者未在设备上配置有效密钥，应用可能提示 **配置不完整**——此时需由技术人员在构建配置中填入合法密钥后重新安装（一般用户可忽略此条，由交付方处理）。

> 此处可插入：隐私同意页、权限请求界面截图

### 首页

打开应用并通过上述门禁后，进入 **首页**。首页通常包括：

- **导航入口：** 进入步行导航相关功能。
- **文字识别（OCR）入口：** 进入拍照/相册识图与朗读。
- **底部或明显位置：** 进入 **设置**、**帮助**。

界面采用 **高对比** 风格，并支持读屏软件逐项朗读控件说明。

> 此处可插入：应用首页截图

### 导航

在导航模块中，您可以：

1. 在具备定位与麦克风等权限的前提下，通过 **语音** 等方式输入或确认 **目的地**。
2. 等待 **路线规划** 完成后，按照 **语音提示**（及必要时 **震动**）沿路线行走。
3. 使用界面上的控制项进行 **暂停、继续、结束** 等操作（具体按钮名称以实际界面为准）。
4. 在导航过程中，应用可能叠加 **障碍提醒**、**交通灯相关提示**（实现方式随版本可能调整）；请始终注意真实路况，软件提示不能替代您对环境的判断。

> 此处可插入：导航待机页、导航进行中的界面截图

### 文字识别（OCR）

在 OCR 模块中，您可以：

1. 使用 **拍照** 或从 **相册** 选择一张图片。
2. 在光线不足时，可尝试打开 **补光（闪光灯）**（若设备与版本支持）。
3. 识别成功后，界面会显示文字，并通过 **语音朗读**；您一般还可以 **复制** 文本或 **重复播放** 朗读。
4. 若识别失败，请检查网络、相机权限、图片清晰度与光线，并重试。

> 此处可插入：OCR 拍照界面、识别结果界面截图

### 设置

在设置中，您通常可以：

- 调节 **语音播报语速**。
- 打开或关闭 **震动** 反馈。
- 设置或清空 **家庭地址**（具体用途以版本说明为准）。
- 在合规设计下执行 **隐私相关操作**（如撤回同意等，操作后可能影响地图或联网能力，请谨慎并在提示下确认）。

设置项会在可能范围内 **保存**，下次打开应用仍然生效。

帮助中心提供关于 **导航、OCR、震动反馈** 等的文字说明，适合首次使用或与家属一起阅读。

### 无障碍与读屏（TalkBack）

若您使用 **TalkBack** 等读屏软件：

- 请打开系统无障碍服务后，在首页、导航、OCR、设置等页面 **顺序浏览焦点**，听取控件的 **名称与状态**。
- 部分动态提示会通过 **实时可读区域** 播报，便于了解识别进度或导航状态变化。

> 此处可插入：在读屏开启状态下聚焦某一按钮的截图（可选）

### 使用注意与常见问题提示

- **安全：** 过马路、上下台阶时请以听觉、触觉与环境判断为主，勿完全依赖软件。
- **网络与密钥：** 地图、语音、识别异常时，可检查网络；若多次失败请联系技术支持（可能涉及服务端或密钥配置）。
- **权限：** 在系统设置中为 EarRove 打开定位、相机、麦克风等权限，可显著减少「无法导航」「无法拍照识别」类问题。

更详细的故障排除与开发构建说明，请参阅仓库根目录 `README.md` 与同目录 `使用说明-详细版.md`。
