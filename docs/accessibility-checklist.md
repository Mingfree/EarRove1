## 发布前无障碍验收清单（EarRove）

### TalkBack 基础可操作性
- [ ] **全局导航**：首页 → 导航/文字识别/设置/帮助均可完成进入与返回
- [ ] **焦点顺序**：关键操作（开始导航、拍照识别、保存设置）焦点顺序自然
- [ ] **无标签按钮**：全应用不出现“未加标签的按钮”
- [ ] **动态状态提示**：识别中/识别完成/初始化中等状态变化可被读屏感知

### 权限路径（异常场景）
- [ ] **首次授权**：定位/相机/麦克风申请流程可理解、可继续
- [ ] **拒绝一次**：拒绝后有明确提示与可继续入口
- [ ] **永久拒绝**：出现“去系统设置开启权限”引导且按钮可用

### 隐私同意流程
- [ ] **首次进入**：隐私同意页面可完整读屏操作，能查看详细条款并返回
- [ ] **不同意**：不同意时退出/拦截逻辑符合预期
- [ ] **设置撤回**：设置页可撤回同意，撤回后重新进入相关能力被正确拦截并引导

### 语音与震动反馈
- [ ] **仲裁优先级**：障碍物 > 导航指令 > OCR > 普通信息，抢占顺序符合预期
- [ ] **震动开关**：关闭震动后不再输出任何震动；开启后恢复
- [ ] **朗读速度**：调整后立即生效，重启应用后保持

### 关键流程走查（建议至少 1 次全链路）
- [ ] **导航**：从首页进入导航 → 语音输入目的地 → 开始导航 → 暂停/继续/结束
- [ ] **文字识别**：从首页进入识别 → 拍照/相册识别 → 重播/复制结果
