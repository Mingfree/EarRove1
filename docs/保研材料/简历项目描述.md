## 一、主版本（三段式：项目背景 / 负责任务 / 成果收获，各 150–250 字）

> 保研简历「项目经历」常用三段式排版；每段均可整段粘贴，也可自行合并为一段。各段字数见文件末尾的校验表。

**【项目背景】**

EarRove聆途——基于多模态感知的视障辅助平台，是一款面向视障人群的 Android 无障碍出行辅助应用。针对视障人群户外出行中环境感知、寻路定位与视觉信息获取的三重困境，本平台构建"语音感知—语义理解—空间定位—视觉感知—多通道反馈"的端云协同多模态流水线，以语音导航与文字识别两大功能覆盖视障出行高频场景，并通过语音+震动双通道反馈与高对比深色主题落实 WCAG 无障碍规范。项目系北京市级大学生科学研究与创业行动计划项目，三人团队协同开发。

**【负责任务】**

作为核心开发成员，负责多模态交互与整体架构：①设计并实现基于优先级抢占的多模态播报仲裁机制，统一调度语音合成与震动双通道，解决导航、障碍、OCR 等多事件源并发播报冲突；②构建 MVVM 三层分层架构与导航六态状态机，实现"待机—监听—规划—导航—暂停—到达"全流程状态管理；③主导流式语音识别链路，基于 WebSocket 流式 ASR 与手写 RMS 静音检测实现免按键语音导航，经大语言模型提取口语目的地、联动 POI 检索与路径规划；④集成 CameraX 与云端多模态大模型完成拍照文字识别。

**【成果收获】**

项目成果：登记计算机软件著作权 1 项（EarRove聆途App V1.0，登记号 2026SR0777492）；获 2026 年（第 19 届）中国大学生计算机设计大赛北京市二等奖；以北京市级大学生科研与创业行动计划项目验收合格。个人收获：掌握了流式语音识别、大语言模型意图理解、多模态视觉理解等前沿技术的移动端工程化落地，建立了从需求分析、架构设计到测试交付的工程方法论；在仲裁机制设计中将"多事件并发"抽象为通道资源调度问题，认识到无障碍产品须以用户认知负荷为设计核心，为后续多模态人工智能研究打下基础。

## 三、要点版（bullet，适配分条排版）

- **多模态感知闭环**：语音 → 语义 → 定位 → 视觉 → 反馈的端云协同流水线，覆盖视障出行两大场景（语音导航、文字识别）
- **多模态播报仲裁（本人核心）**：基于优先级抢占的仲裁机制，统一调度 TTS 与震动双通道，解决多事件源并发播报冲突
- **流式语音导航**：Paraformer 流式 ASR + 手写 RMS 静音检测实现免按键交互，LLM 提取口语目的地，联动 POI 检索与步行路径规划
- **拍照文字识别**：CameraX 拍摄 + 端侧压缩 + 云端多模态大模型识别 + TTS 朗读
- **架构与无障碍**：MVVM 三层分层 + 导航六态状态机；WCAG 规范高对比深色主题与读屏语义标注
- **成果**：软件著作权 1 项；中国大学生计算机设计大赛北京市二等奖；北京市级大创项目验收合格

## 四、英文版（English · ~150 words）

**EarRove Listening — A Multimodal Perception-based Assistive Platform for the Visually Impaired**

An Android accessibility system enabling barrier-free outdoor navigation and text reading for the visually impaired, built around an end-cloud collaborative multimodal pipeline (speech perception → semantic understanding → spatial localization → visual perception → multi-channel feedback). As a core developer, I led the multimodal interaction and overall architecture: designed a priority-preemption broadcast arbitration mechanism that unifies TTS and haptic feedback to resolve conflicts among concurrent event sources; built the layered MVVM architecture and a six-state navigation state machine; implemented hands-free voice navigation based on streaming ASR (Paraformer) with hand-written RMS silence detection, LLM-based spoken-destination extraction, POI search and pedestrian route planning; and integrated CameraX with a cloud multimodal LLM for photograph-based text recognition, following WCAG guidelines for high-contrast theming and accessibility semantics. Outcomes: a registered software copyright (2026SR0777492), Second Prize in the 2026 (19th) China Collegiate Computing Competition (Beijing division), and a qualified Beijing Municipal College Student Research & Entrepreneurship project.
