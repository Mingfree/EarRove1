| 项 | 说明 |
| --- | --- |
| 文档版本 | v1.0 |
| 适用版本 | 以仓库当前实现为准（Kotlin + Compose，minSdk 26） |

## 1. 测试范围与模块映射

| 模块 | 范围摘要 |
| --- | --- |
| 启动门禁 | 双隐私同意、配置校验、核心权限引导 |
| 首页 | 导航/OCR 入口、底部设置与帮助 |
| 导航 | 状态机（待机/监听/规划/导航/暂停/到达）、路线与控制栏、障碍与交通灯叠加层 |

| 帮助 | 说明文案展示 |
| 无障碍 | TalkBack、live region、高对比主题 |
| 仲裁与反馈 | 事件优先级（障碍 > 导航 > OCR > 信息）、语音与震动 |

## 2. 环境与前置条件（通用）

- **硬件：** 建议真机（定位、相机、麦克风、震动）。
- **构建：** 已按 `config.sample.properties` 配置有效 `local.properties`（非占位符密钥）。
- **网络：** 导航/OCR 云端链路需网络时，按用例注明「需网络」。

## 3. 启动与合规

| 测试编号 | 测试目标 | 输入条件 | 预期结果 | 实际结果 |
| --- | --- | --- | --- | --- |
| TC-S01 | 应用隐私政策未同意时拦截主流程 | 首次安装启动，仅查看或拒绝应用隐私 | 不可进入主应用，直至完成应用侧同意流程 | |
| TC-S02 | 百度地图隐私未同意时拦截主流程 | 已同意应用隐私，未同意地图隐私 | 不可进入主应用，直至地图隐私同意 | |
| TC-S03 | 双同意后进入主流程 | 依次同意应用隐私与百度地图隐私 | 进入后续门禁或主页（按实现顺序） | |
| TC-S04 | 配置占位符拦截 | `local.properties` 中关键项仍为 `YOUR-*` 等占位符，启动应用 | `ConfigValidator` 提示明确修复说明，提供重试；不静默失败 | |
| TC-S05 | 配置修复后重试 | 在 TC-S04 基础上修正配置并点击重试 | 通过配置门禁，进入权限门禁或主页 | |
| TC-S06 | 定位权限首次请求 | 清理应用数据后启动，流程到达权限门禁 | 出现定位相关引导，用户可选择允许/拒绝 | |
| TC-S07 | 相机权限首次请求 | 同上，流程要求相机 | 出现相机权限引导 | |
| TC-S08 | 麦克风权限首次请求 | 同上，流程要求麦克风 | 出现麦克风权限引导 | |
| TC-S09 | 权限永久拒绝修复路径 | 在系统设置中永久拒绝定位（或相机/麦克风），返回应用 | 提示前往系统设置修复，降级或阻塞行为符合产品设计 | |
| TC-S10 | 部分权限拒绝仍可继续（降级） | 拒绝非致命权限（若实现支持「继续」） | 应用给出可理解的降级说明，不崩溃 | |

## 5. 导航（状态机与操作）

| TC-N10 | 交通灯叠加层（演示逻辑） | 导航中接近路口或触发演示 | UI/语音展示红绿灯与倒计时（当前实现若为模拟，与说明文档一致即可） | |
| TC-N11 | 障碍警示层 | 触发障碍检测信号（依实现） | 高优先级提示覆盖；与仲裁规则一致 | |

## 7. 设置

| 测试编号 | 测试目标 | 输入条件 | 预期结果 | 实际结果 |
| --- | --- | --- | --- | --- |
| TC-ST01 | 语速边界 - 最小 | 语速滑块调至约 0.5 | TTS 语速明显变慢，保存后重启仍生效 | |

| TC-ST04 | 震动开关关闭 | 关闭震动 | 后续仲裁震动不触发或符合降级说明 | |
| TC-ST05 | 震动开关开启 | 开启震动 | 在应有场景下可感知震动 | |
| TC-ST06 | 家庭地址 - 保存 | 输入合法地址文本并保存 | 再次进入设置仍显示已保存内容 | |
| TC-ST07 | 家庭地址 - 清空 | 清空家庭地址并保存 | 字段为空，持久化一致 | |
| TC-ST08 | 隐私撤回 | 点击隐私撤回并确认 | 按设计重置同意状态或能力；再次启动走隐私门禁 | |
| TC-ST09 | 隐私撤回取消 | 弹出确认框点击取消 | 不撤回，当前会话状态不变 | |
